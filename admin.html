账号与密码

都在 Vercel 里，不在网页上

现在的账号
admin
密码存在哪
不存在网页和数据库里，存在 Vercel 项目的环境变量 ADMIN_PASSWORD_HASH 里，是一串加密后的哈希。
怎么改密码
在本机跑 node tools/hash-password.js 新密码，把输出的那行哈希贴回 Vercel 的 ADMIN_PASSWORD_HASH，保存后重新部署一次。
怎么改账号
Vercel 环境变量 ADMIN_USERNAME，不填默认就是 admin。
忘记密码怎么办
走上面「怎么改密码」同样的步骤，直接换成新密码即可，不需要旧密码。
别人能猜到吗

这个后台

它怎么工作的

内容存在哪
都存在你的私有仓库 Private-admin 里：文章是 posts/ 下的 Markdown 文件，首页文案是 site.json，图片在 images/。
为什么别人看不到
网页本身不含任何文章内容。每次打开首页，是 Vercel 的函数去私有仓库读一遍，判断你登没登录，才决定发什么回来。
改完为什么能马上看到
保存时直接写进仓库，服务器缓存 15 秒，所以最多等十几秒。
删掉的文章能找回吗
能。仓库有历史记录，去 GitHub 的 Commits 里能找到那一版。
